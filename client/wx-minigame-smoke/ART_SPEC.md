# 角色多角度立绘规格（ART SPEC）

人物界面 360° 旋转需要多角度立绘。当前只有「正面」立绘，背面用镜像占位。
若要达到真实效果，请按本规格生成/提供其余角度的立绘，放入 `images/` 目录即可自动生效（代码已支持，无需改代码）。

## 一、需要的角度（推荐 4 方向起步，8 方向最佳）

| 角度 | 含义 | 文件后缀 |
|------|------|---------|
| 0°    | 正面 | （无后缀，现有 `hero_male.png` 等） |
| 90°   | 右侧面 | `_right` |
| 180°  | 背面 | `_back` |
| 270°  | 左侧面 | `_left` |

可选更细（8 方向）：再补 `_front_right`(45°)、`_back_right`(135°)、`_back_left`(225°)、`_front_left`(315°)。

## 二、文件命名

对每一套时装，正面图名为 `<base>.png`，其余角度为 `<base>_back.png`、`<base>_left.png`、`<base>_right.png`。

现有 12 套时装基础名：
```
hero_male  hero_female  hero_blue  hero_gold  hero_red  hero_female_blue
hero_purple  hero_teal  hero_orange  hero_pink  hero_violet  hero_cyan
```

示例：正面 `hero_male.png` → 背面 `hero_male_back.png`、右侧 `hero_male_right.png`、左侧 `hero_male_left.png`。

> 当前 `*_back.png` 已由脚本镜像生成（占位），可被真实背面图直接覆盖替换。

## 三、图像要求

- **格式**：PNG，透明背景（alpha 通道）。
- **人物朝向**：正面朝观察者，全身完整、居中、脚底与底边齐平。
- **同一套各角度必须同尺寸、同脚底基线、同缩放**，否则旋转时会跳动。
- **同一角色各角度风格/配色/服饰完全一致**（同一角色、同一套服装、同一发型，仅视角不同）。
- 建议尺寸：宽 ≤ 512px、高 ≤ 1024px（竖版全身）；现有立绘约 160×284 显示尺寸，可等比放大生成。

## 四、AI 生图提示词模板（供外部工具参考）

> 以正面图为参考图，逐角度生成同一角色的其他视角。

```
参考图：<正面立绘>
生成一张同角色的全身立绘，视角为「背面 / 右侧面 / 左侧面 / 右后 45° / …」，
保持完全相同的角色身份、发型、服饰、配色、画风，PNG 透明背景，
全身完整居中、脚底与底边齐平，与参考图同尺寸同缩放。
仙侠国风，高清，游戏立绘。
```

## 五、代码接入状态

- `game.js` 的 `drawHeroSpinning()` 已支持「正面 + 背面」两角度：背面优先读 `IMG[img+'Back']`，缺省自动镜像兜底。
- 放入 `_left.png` / `_right.png` 后，需要我再把「侧面」也接入旋转（当前侧面仍是柱面近似过渡），或你想让我现在就接好 4/8 方向切换，我也可以直接改。

## 六、如何自己生成（可选工具）

- 通义万相 / 即梦 / Midjourney / Stable Diffusion / ComfyUI 等，用上面的提示词模板逐张生成，再套用现有 `cutout.py`（GrabCut 抠图）与 `defringe.py`（去白边）处理透明背景。
